# Draft manuscript

Final thesis prose written by the Writing agent only.

## Naming convention

```
01-introduction.md
02-background.md
03-methodology.md
04-results-rq1.md
04-results-rq2.md
…
05-discussion.md
06-conclusion.md
```

Use `04-results-rqX.md` per research question or merge into `04-results.md` if preferred.

## Before writing a section

1. Read existing draft files for terminology and tone consistency
2. Read `thesis/workspace/synthesis/` and `thesis/workspace/analysis/` for the relevant RQ
3. Check `thesis/workspace/critique/` — do not draft if verdict is `blocked` unless user overrides
4. Follow `.cursor/agents/writing_agent.md` (academic writing rules inlined)

## Citations

APA 7. Source slugs from `thesis/references/_index.md`; converted text in `thesis/references/processed/{slug}/paper.md`.
